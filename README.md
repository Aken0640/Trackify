# Trackify

Trackify is a Python-based Expense Tracker application with a modern GUI built using Tkinter.

It allows users to:
- Track income and expenses
- Categorize transactions
- Monitor balance summaries
- Visualize expenses with interactive charts

---

## Features

- Modern GUI Interface
- Expense & Income Tracking
- Category-based Transactions
- CSV Data Storage
- Interactive Expense Pie Chart
- Real-time Balance Updates

---

## Technologies Used

- Python
- Tkinter
- Matplotlib
- tkcalendar

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Aken0640/Trackify.git
```

Move into the project folder:

```bash
cd Trackify
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
